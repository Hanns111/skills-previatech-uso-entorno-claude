# Versión 9.3 — 2026-04-06 11:58 (hora de Lima)

## Cambios introducidos
- **Nueva regla obligatoria de auto-montaje**: si el usuario menciona o pega una ruta de carpeta de expediente que no está montada, el agente debe montarla automáticamente con `request_cowork_directory` sin preguntar.
- Prohibido preguntar "¿quieres que la monte?" o sugerir un expediente alternativo ya montado.
- Aplica también cuando el usuario adjunta una captura del Explorador de Windows con la ruta visible.
- **Filtro estricto en revisión por armada posterior**: para armadas >=2 el checklist en Excel NO debe mostrar documentos base (TDR, ECR, CCI, anexos del proveedor, certificación). Solo aparecen los exigibles por armada (Conformidad, Informe técnico, Entregable, RHE, Constancia 1609, Proveído de Devengado).
