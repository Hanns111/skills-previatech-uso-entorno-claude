# v9.4 — 2026-04-06 12:30 (Lima)

## Cambios

1. **Hyperlinks del Excel corregidos**
   - `build_link()` ahora URL-encodea la ruta y el nombre del archivo con `urllib.parse.quote(safe="/:")`, de modo que los espacios pasen a `%20` y Adobe/Foxit reconozcan correctamente el sufijo `#page=N`.
   - Antes el clic abría el PDF en la página 1 cuando la ruta contenía espacios o caracteres especiales.

2. **Orden canónico del checklist (regla del usuario)**
   - Nueva función `prioridad(item_name)` y lista `ORDEN_CANONICO` con regex.
   - Orden exigido: Proveído → Conformidad (+ Informe Técnico) → Constancia de Recepción → Certificación/CCI → Compromiso de Pago → Suspensión 4ta (1609) / RHE / Factura → OS/OC → Carta Contrato → Entregable → resto.
   - En primera armada se unifica `base + porarmada` en una sola sección ordenada.
   - En armadas posteriores se aplica el mismo orden sobre los ítems `por armada`.

3. **Verificación tributaria ampliada**
   - Nuevos campos en el bloque `tributario` del JSON y en la hoja "Tributario" del Excel:
     - `condicion_pago` (al contado / al crédito)
     - `aplica_retencion` (SI/NO)
     - `aplica_detraccion` (SI/NO) + `tasa_detraccion`, `monto_detraccion`, `constancia_detraccion`
   - Para facturas al crédito: validar que la fecha de pago esté dentro del plazo del proveído.

4. **SKILL.md**
   - Línea de versión actualizada a v9.4.
   - Nueva sección "Orden canónico del checklist".
   - Nueva sección "Hyperlinks del Excel" con la regla de verificación obligatoria (re-leer cada PDF en la página indicada antes de entregar).
   - Nueva sección "Verificación tributaria ampliada".
